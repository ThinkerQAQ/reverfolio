# Contributing

Start by fetching the latest main branch. Work on a focused feature branch and open a pull request. Use Squash Merge and delete the branch after merging. Do not rewrite or delete main.

Describe the concrete behavior, scope, validation and remaining limitations. Update English and Chinese user documentation when behavior changes. Run documentation checks; once application code exists, run its relevant tests and platform gates.

Use synthetic fixtures. Never commit tokens, cookies, local databases, raw personal analytics, private historical reports, browser profiles or full third-party article archives. Preserve upstream notices when introducing code and record dependency versions.

This private repository is currently in the planning stage. Public contribution workflows and release installation instructions will be added when applicable.
