# Reverfolio original visual identity

The project logo is an independent blue rounded-square graphic with a white origin dot and three quarter-circle echo waves. It symbolizes detecting and verifying the propagation of open-source and written work.

- Source vector: reverfolio-icon.svg
- Browser favicons: internal/echo/web/favicon.svg (copied source)
- Browser extension icons: extension/icons/icon16.png, icon32.png, icon48.png, icon128.png, icon256.png
- Windows shortcut/application icon: extension/icons/reverfolio.ico
- Windows Go executable icon resources: cmd/reverfolio/rsrc_windows_amd64.syso and rsrc_windows_arm64.syso

All derived resources are committed so consumers do not need FFmpeg or extra build dependencies. Maintainers can rerun scripts/build-icons.sh to regenerate them using FFmpeg and the pinned github.com/akavel/rsrc v0.10.2 resource compiler. The vector artwork belongs to the Reverfolio project and is licensed with the repository (unless separately stated). No BlogCTL assets are reused.
